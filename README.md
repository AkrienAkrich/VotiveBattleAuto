# VotiveBattleAuto

WinForms-приложение для автоматизации РП-боя по логике Votive: стороны, участники, инициатива, автоходы, физические/магические атаки, контроль, массовые способности, формы, лечение, кулдауны и лог боя.

## Где менять правила и способности

Справочники лежат в папке проекта:

- `VotiveBattleAuto/Data/races.json` — расы, формы.
- `VotiveBattleAuto/Data/roles.json` — роли.
- `VotiveBattleAuto/Data/abilities.json` — способности магии, охотников, оборотней и вампиров.

Приложение сделано так, чтобы точные способности можно было быстро перенести в JSON без переписывания C#.

## Основные теги

- `Hunter` — охотник.
- `Lycan` — оборотень.
- `Vampire` — вампир.
- `Monster` — чудовище/сверхъестественная цель.
- `Undead` — нежить.
- `Mage` — маг.
- `Warrior` — воин.
- `Veteran` — опытный воин.
- `SilverWeapon` — можно вручную добавить персонажу, если у него есть серебряное оружие.

## Логика бросков

- Физическая атака: `1d12 + атака` против `1d12 + защита`.
- Магическая атака: `1d12 + маг. атака` против `1d12 + маг. защита`.
- Побег: `1d12 + побег` против максимального `1d12 + побег` противников.
- При равенстве атаки и защиты движок автоматически делает перекид.
- Участник по умолчанию имеет 3 HP.

## Функционал

- Несколько сторон боя.
- Несколько участников на каждой стороне.
- Ручной ход.
- Автоход.
- Автобой до победы одной стороны.
- Контроль через магическую атаку + спас-бросок d12.
- Массовые атаки и массовый контроль.
- Кулдауны способностей.
- Статусы: пропуск действия, запрет побега, модификаторы статов, форма.
- Редактируемые JSON-справочники.
